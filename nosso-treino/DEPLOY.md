# Publicação

- Produção: https://nosso-treino.vercel.app
- Branch de produção: `nosso-treino`
- Hospedagem: Vercel
- Tipo: site estático instalável
- Persistência: armazenamento local do aparelho

## Configuração recomendada no Vercel

1. Conecte o repositório `Sagittaryuz/studio`.
2. Selecione a branch de produção `nosso-treino`.
3. Use a raiz do repositório ou defina Root Directory como `nosso-treino`; há um `vercel.json` para cada caso.
4. Não envie somente o `index.html` manualmente. O aplicativo precisa também de `app.js`, `styles.css`, `manifest.webmanifest`, `sw.js` e `icon.svg`.

O deploy que estava em produção foi enviado manualmente como um único arquivo e não correspondia ao código desta branch.
